# BlackBreak — Windows Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A small Windows tray app that blacks out every monitor for 30 s every 20 min on its own Win32 desktop, survives being killed, and allows only the pre-set pause, the same as the Linux extension.

**Architecture:** `BlackBreak.Core` (net10.0, no Windows APIs) contains the C# port of `scheduler.js` plus pure helpers for break resume and call detection. It is proven by `spec/scenarios.json` and `spec/traces.json`, and xunit runs it on Linux and on CI. `BlackBreak` (net10.0-windows, plain P/Invoke, no WinForms/WPF, NativeAOT) contains the tray, the warning notice, the break desktop, the keyboard hook and the watchdog. It is one exe; `--watchdog` runs it as the watchdog.

**Tech Stack:** C# 14 / .NET 10 LTS, NativeAOT win-x64, xunit, GitHub Actions `windows-latest`.

**Spec:** `docs/superpowers/specs/2026-10-23-blackbreak-design.md` (Platforms → Windows). Also `2026-10-23-shared-traces-release.md` (trace format, asset names, versioning).

## Global Constraints

- All timing values, the four break lines, the colours, `Break in 10 s`, the 35 s fail-safe, pause and call rules: as in `2026-10-23-linux-gnome.md` Global Constraints, verbatim.
- **Spec amendment (owner decides at plan review):** .NET 10 LTS instead of .NET 8, because .NET 8 support ends 2026-11-10. NativeAOT with no UI framework keeps the exe at a few MB instead of about 70 MB.
- **Spec amendment:** settings are three check items in the tray menu (`Wait with the break while I'm in a call`, `Microphone in use`, `Camera in use`) instead of a dialog. These are native and smaller, and like the dialog they are greyed in warning and break.
- Tray menu: status line (`Next break at HH:MM`, `Paused until HH:MM`), `Pause 30 min`, `Pause 1 hour`, `Pause 2 hours`, `Pause 3 hours`, `Cancel pause`, separator, the three call items, separator, `Quit`. Pause items are disabled unless `canPause`. `Quit` and the call items are disabled in warning and break.
- Files: `%LOCALAPPDATA%\BlackBreak\settings.json` (`callExemption`, `exemptMic`, `exemptCamera`, `lastPauseDay`) and `%LOCALAPPDATA%\BlackBreak\state.json` (`breakStartMs`, `bootMs`).
- Autostart: on every start the app writes `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` value `BlackBreak` = `"<exe path>"`.
- Names: mutex `Local\BlackBreak.App`, mutex `Local\BlackBreak.Watchdog`, event `Local\BlackBreak.Quit`, desktop `BlackBreak`.
- Debug: environment variable `BLACKBREAK_DEBUG_FAST=1` → scale 60. `--smoke <seconds>` → logs every phase change to stdout and exits after the given time (used by CI).

## Review Focus

- **Ctrl+Alt+Del during a break, then Cancel** → Windows returns to the Default desktop and the break is no longer visible. Expected: within 250 ms the break desktop is input again. Task 3: a 250 ms timer calls `SwitchDesktop` while the input desktop is not `BlackBreak`.
- **Process killed in a break (Task Manager behind the secure screen)** → the watchdog relaunches the app. The relaunch shows only what is left of the original 30 s, and never shows anything after `breakStart + 35 s`. Task 2 `BreakResume` tests, plus the Task 4 smoke test.
- **Both processes killed, or the app crashes in the break** → the black desktop must not stay. Task 3: the watchdog itself switches to Default once `breakStart + 35 s` has passed while the input desktop is still `BlackBreak`.
- **Monitor added or removed, or DPI changed, during a break** → every monitor is black. Task 3 handles `WM_DISPLAYCHANGE` by recreating the windows; manual item.
- **Sleep or hibernate with the lid closed during a break, then resume** → no black screen on resume (scheduler gap rule). Task 3: on `WM_POWERBROADCAST` `PBT_APMRESUMEAUTOMATIC` the app ticks at once, before painting.

### Task 2: Resume, call usage, store

**Interfaces — produces:**
- `static class BreakResume { static long? EndsAt(long? breakStartMs, long? savedBootMs, long nowMs, long bootMs) }`. It returns the end of the break to show now, or `null`. Rules:
  - `null` when the boot changed (`|savedBootMs − bootMs| > 120000`), which means a reboot discards the state;
  - `null` when `now ≥ breakStart + BreakMs`;
  - otherwise `breakStart + BreakMs`.
  - Callers also arm a hard fail-safe at `breakStart + FailsafeMs`.
- `static class CallUsage { static bool InUse(IEnumerable<(string app, long start, long stop)> entries, string selfExe) }`. It is true when any entry has `start > 0 && stop == 0` and the app path is not `selfExe`.
- `sealed record Settings(bool CallExemption = false, bool ExemptMic = true, bool ExemptCamera = true, string? LastPauseDay = null)`; `sealed record BreakState(long? BreakStartMs, long BootMs)`.
- `static class Store { Settings LoadSettings(string dir); void Save(string dir, Settings s); BreakState? LoadState(string dir); void Save(string dir, BreakState s); }`. A missing or corrupt file gives the defaults (`null` for state) and never throws. Writes are atomic (temp file, then `File.Move(overwrite: true)`).

- [ ] **Step 1: Failing tests:**

  - `CallUsage`: `active entry counts`, `stopped entry does not`, `never used does not`, `self is skipped`.
  - `Store`: `round trip`, `corrupt file gives defaults`, `missing dir gives defaults`.

### Task 3: Break desktop, notice, watchdog

**Files:** `windows/App/BlackBreak.csproj`, `Native.cs`, `BreakDesktop.cs`, `Notice.cs`, `Watchdog.cs`, `app.manifest`, `windows/test/manual-checklist.md`.

**Interfaces — produces:**
- `sealed class BreakDesktop : IDisposable { void Show(long endsAtMs, long failsafeAtMs); void Hide(); bool Visible { get; } }`.
  - `Show` runs on its own STA thread: `CreateDesktop("BlackBreak")`, `SetThreadDesktop`, one black topmost popup per monitor (`EnumDisplayMonitors`), the four lines and the countdown on the primary monitor, `SwitchDesktop`, and `WH_KEYBOARD_LL` on that thread swallowing every key.
  - Text: GDI `DrawText`, font "Segoe UI Light". The lines are `#9A9A9A`, the countdown `#5A5A5A` and smaller.
  - The countdown repaints on each whole second and the desktop hides itself at `endsAtMs`.
  - An independent timer at `failsafeAtMs` always hides.
  - A 250 ms timer re-calls `SwitchDesktop` while `OpenInputDesktop` does not name `BlackBreak`.
  - `Hide` switches back to `Default`, closes the desktop and ends the thread. With `--smoke`, it logs `desktop switched` after a successful `SwitchDesktop` and `desktop restored` after the switch back.
- `sealed class Notice : IDisposable { void Show(string text); void Hide(); }`: a layered, `WS_EX_TRANSPARENT | WS_EX_TOPMOST | WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW` window, top-centre of the primary monitor, dark grey pill, light text.
- `static class Watchdog { static int Run(string exePath); static void EnsureRunning(string exePath); static void SignalQuit(); }`.
  - In `--watchdog` mode it holds `Local\BlackBreak.Watchdog`. It waits on the app's process handle and on `Local\BlackBreak.Quit`.
  - When the app dies and Quit is not set, it relaunches the app after 1 s.
  - Every second, if `state.json` has `breakStartMs`, `now > breakStart + 35000`, and the input desktop is `BlackBreak`, it calls `SwitchDesktop(Default)`.
  - The app calls `EnsureRunning` on every tick, so the processes guard each other.

  - no input (Win, Alt+Tab, Alt+F4, Ctrl+Esc, Win+L does lock, mouse);

### Task 4: Tray, call detection, wiring, CI smoke

**Interfaces — consumes:** Tasks 1–3. **Produces:** `BlackBreak.exe`.

- `Program.Main(args)`:
  - `--watchdog` → `Watchdog.Run`.
  - Otherwise: take the single-instance mutex (exit 0 if it is held), write the Run key, load settings and state, and call `BreakResume.EndsAt` (if it is non-null, show the break first).
  - Then create `Scheduler(now, scale, lastPauseDay)` and a hidden message window with a 1 s `SetTimer` tick.
- Tick:
  - `idleMs` comes from `GetLastInputInfo` against `GetTickCount64`.
  - `inCall` comes from `CallDetector`, polled only from 60 s before the warning is due and while held, the same window as `linux/…/extension.js`.
  - On a phase change: warning → `notice.Show("Break in 10 s")`; break → write `state.json`, `notice.Hide()`, `breakDesktop.Show(endsAt, breakStart+35000)`; work/paused → hide both and clear `breakStartMs`.
  - After a successful `Pause`, save `lastPauseDay`.
  - Settings changes made in warning or break are not possible (the items are greyed). The call settings are snapshotted at each normal-work tick, as in Linux.
- `CallDetector.InCall()`: reads `HKCU\…\CapabilityAccessManager\ConsentStore\{microphone,webcam}` and their `NonPackaged` subkeys (`LastUsedTimeStart`, `LastUsedTimeStop` QWORDs), then calls `CallUsage.InUse`. It returns false when the exemption is off.
- Tray: `Shell_NotifyIcon` with `app.ico`, tooltip `BlackBreak`; a right or left click opens a `TrackPopupMenu` with the Global Constraints menu. `Quit` → `Watchdog.SignalQuit()`, remove the icon, exit.
